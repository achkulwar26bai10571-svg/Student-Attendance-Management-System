\# Student Attendance Management System



\## Introduction



The Student Attendance Management System is a Python-based console application used to manage student attendance.



The system allows users to add students, manage subjects, mark attendance, calculate attendance percentages, view reports, and maintain attendance history.



\## Features



\- Add student

\- Show students

\- Edit student details

\- Delete student

\- Search student

\- Mark attendance

\- View attendance report

\- Show students below 75% attendance

\- Calculate class statistics

\- Add subjects

\- Mark subject-wise attendance

\- View subject reports

\- Attendance dashboard

\- Maintain attendance history with date

\##Main Modules

Student Management



Manages student records including adding, editing, deleting, searching, and displaying students.



Attendance Management



Allows attendance to be marked as Present or Absent.



Subject Management



Allows subjects to be added and attendance to be maintained for individual subjects.



Reports



Provides student attendance reports, subject reports, defaulter reports, and class statistics.



Dashboard



Displays overall attendance information in one place.



Attendance History



Stores attendance records with date, subject, and attendance status while the program is running.



Attendance Calculation



Attendance percentage is calculated using:



Attendance Percentage = (Present Classes / Total Classes) × 100



Students with attendance of 75% or above are shown as Eligible.



Students below 75% are shown as having an Attendance Shortage.



\##Limitations

Data is stored in memory using Python dictionaries.

Data is lost when the program is closed.

The application currently uses a console-based interface.
