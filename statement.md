\# Project Statement



\## Project Title



Student Attendance Management System



\## Problem Statement



Managing student attendance manually can take time and may lead to calculation errors. Teachers need a simple way to record attendance, calculate percentages, identify students with low attendance, and view attendance reports.



\## Proposed Solution



The Student Attendance Management System is a Python console application that provides functions for managing students, subjects, attendance records, and reports.



\## Objectives



\- Manage student information.

\- Record student attendance.

\- Manage subject-wise attendance.

\- Calculate attendance percentages.

\- Identify students below the required attendance level.

\- Provide class statistics.

\- Maintain attendance history.

\- Provide a simple dashboard.



\## Functional Requirements



1\. Add student.

2\. Display students.

3\. Edit student.

4\. Delete student.

5\. Search student.

6\. Mark attendance.

7\. Display attendance report.

8\. Add subjects.

9\. Mark subject attendance.

10\. Generate subject reports.

11\. Generate defaulter reports.

12\. Display class statistics.

13\. Display dashboard.

14\. Maintain attendance history.



\## Non-Functional Requirements



\### Usability

The application provides a simple menu-based interface.



\### Reliability

The program checks whether students and subjects exist before performing operations.



\### Maintainability

The project is divided into separate Python functions for different operations.



\### Error Handling

Invalid menu choices, student numbers, subjects, and attendance choices are handled with appropriate messages.



\## Technology



Python 3.x is used to develop the project.



\## Future Scope



The project can be extended with database storage, a graphical user interface, authentication, and advanced attendance reports.
